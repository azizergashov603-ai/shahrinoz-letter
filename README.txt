САЙТ-ПИСЬМО ДЛЯ ШАХРИНОЗ

Файлы сайта: index.html, style.css, script.js.

МУЗЫКА
Если у тебя есть право использовать этот трек на сайте, переименуй свой аудиофайл в stephanie.m4a и положи его в ту же папку, где находится index.html. Сам аудиофайл в этот архив не включён. Без него сайт откроется, а плеер предложит выбрать аудиофайл вручную.

ПУБЛИКАЦИЯ
1. Загрузи index.html, style.css и script.js в один GitHub-репозиторий.
2. Если добавляешь музыку, загрузи также stephanie.m4a.
3. В Settings → Pages выбери публикацию из ветки main и папки /(root).
4. Дождись появления адреса сайта и только после этого создавай QR-код.

ИСПРАВЛЕНИЕ
Кнопка «назад» и свайп вправо теперь переключают страницу внутри письма и не используют историю браузера.
