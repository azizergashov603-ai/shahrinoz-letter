SH AHRINOZ — VINYL LETTER
Файлы сайта: index.html, style.css, script.js.
Музыка: если у вас есть разрешение на публичное размещение трека, добавьте файл stephanie.mp3 в ту же папку, что и index.html.
Плеер запускается только после нажатия на пластинку; громкость по умолчанию 18%.
На первом экране пластинка выезжает из конверта и вращается. Через несколько секунд появляется короткое извинение, затем письмо из четырёх страниц.
Публикация: загрузите три файла сайта (и разрешённый аудиофайл при наличии) в корень GitHub Pages репозитория.
